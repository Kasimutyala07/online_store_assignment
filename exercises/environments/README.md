# Node.js Basics – Learning Record

## Topic 1: Variables and Price Calculation

**Concepts learned:**
- JavaScript variables using let and const.
- Multiplication and price calculation.
- Variable reassignment.
- Sequential execution of JavaScript statements.

**Experiment:** Calculate product price and update quantity.

**Expected output:**
- Initial total: 747
- Updated total: 1245

**Observed output:**
- Initial total: 747
- Updated total: 1245

**Result:** Successful.

**Learning outcome:**

I learned how JavaScript variables store values and how the let keyword allows reassignment. I also understood how changing a product quantity requires recalculating the total price. This logic will be used in the shopping cart functionality.
